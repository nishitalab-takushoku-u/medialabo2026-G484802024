数当てゲーム

第4回講義で学んだDOM要素の検索とイベント処理を参考し、1から10までの数字を当てる「数当てゲーム」を制作しました。 プログラムでは、Math.floor() を用いてランダムな正解（kotae）を自動生成し、ユーザーがテキストボックスに入力した値を Number() 関数で数値に型変換して判定を行っています。「回答」ボタンを押した際にイベントハンドラ（hantei 関数）が実行されるよう、 addEventListener('click', hantei) を使ってイベントリスナを登録しました！ また、条件分岐（if-else）を用いて、3回以内の正解判定や、外れた場合の大小のヒント、 4回目以降の終了メッセージが p#result 要素 of textContent を通じてページ上にリアルタイムに更新・表示される仕組みを実装できました。 脳の中のアイデアが実際の形になり、動的なWebページ作りの面白さを実感しました!

各授業回の学習事項

第1回WWWとHTML

第1回の実験では、Webページを構築するための最も基本的な言語であるHTMLの役割と、 その正確な記述方法について学習した。Webページは、文字コードを指定する (meta charset="utf-8") や、 ページのタイトルを決める (title) などを配置する (head) 要素と、実際にブラウザの画面上に表示される文章や画像を配置する (body) 要素という、大きく2つの階層構造に分かれていることを理解した。また、見出しを作る (h1) や、段落を構成する (p) などのタグの役割を学び、タグを閉じ忘れるとHTMLが正しく読み取られなくなるという、構文を正確に書くことの重要性を学んだ。 これらを通じて、普段何気なく見ているWebサイトがどのような仕組みで成り立っているのか、 土台となるコンテンツ作成 of 基礎知識を身につけることができました！

演習の成果:演習1-4: HTMLのさまざまな要素

第2回 CSSによる Web ページの装飾

第2回の授業では、CSSによるWebページの装飾について学びました。CSSはHTMLで構成された要素の見た目を変更する技術で、 外部スタイルシートとして別ファイルに記述するのが一般的な方法です。セレクタを使って装飾対象の要素を指定し、 colorやfont-size、background-colorなどのプロパティに値を設定することで文字色やサイズ、背景色などの変更ができます。 また、クラスセレクタや擬似クラス（a:link、a:visited、a:hoverなど）を使うことで、より細かな装飾が可能になりました。 演習では、ウェブブラウザの説明ページのレイアウトをグリッドを使って組み替えたり、各要素のデザインを整えたりする実践的な課題に取り組んできました。

演習の成果:演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScriptの基本

第3回の実験では、Webページに動きや複雑な機能を追加するためのプロパティ言語であるJavaScriptについて学習した。 これまでプログラミングIで学んだJavaは事前にコンパイルが必要な「コンパイル言語」だったのに対し、JavaScriptはコードを1行ずつ読み込みながらその場で実行していく「インタプリタ言語」であるという大きな違いを学んだ。 また、変数宣言には型を指定せず一律で let を使うことや、厳密な比較には記号が1つ多い === や !== を使うというJavaScript特有の構文を理解した。 演習では、外部のJavaScriptファイルを安全に実行するために script タグに defer 属性を必ずつけることや、配列の要素を効率よく処理するための for-of 構文の便利さを学んだ。 さらに、複数のデータをひとまとめにした「オブジェクト」の構造について学び、ドット記号を使って campus.address のように特定のデータ項目を正確に参照してコンソールに出力する技術を習得しました。

演習の成果:演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

第4回講義では、「イベント処理とDOM」というテーマについて学習しました。具体的には、まずユーザーから入力を受け取るための input 要素や、処理を実行するための button 要素といったフォーム要素の配置方法について学びました。 次に、JavaScriptからHTMLを操作するための仕組みである「DOM」について理解を深め、document.querySelector() を使って特定のIDや要素を検索してプログラム内に取り出す方法を学びました。 さらに、取り出した要素の .value を使って入力値を取得したり、.textContent を書き換えてページ上の文字を動的に変更する手法を学びました。最後に、addEventListener() を用いて「ボタンがクリックされたら関数を実行する」というイベントハンドラの登録方法を学び、 ただの静的な画面だったHTMLが、JavaScriptと組み合わせることで一気に動きのあるWebサイトに変わる面白さを体感できました!

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

第5回の講義では、これまでコンソール（`console.log`）に出力していたデータを、プログラムを用いてブラウザ上のHTML画面へ動的に反映させる「DOM操作」を新たに学習しました。 具体的には、`document.querySelector` で特定の要素（`h2#addr` や `h2#dept`）を正確に選択し、`document.createElement` で新しく `p` や `ul`、`li` といった要素をメモリ上に生成する手順を習得しました。 また、生成した要素に `textContent` でテキストを代入したり、`setAttribute` で属性（`src` や `href`）を設定する手法を学びました。 最も重要な新知識として、これらをHTMLに配置する際、`insertAdjacentElement` メソッドを用い、内部の最後を指定する `'beforeend'` や、直後を指定する `'afterend'` といったキーワードで挿入位置を厳密に制御する方法をマスターしました。 さらに、配列データを繰り返し処理する `for-of` 構文を組み合わせ、複数の箇条書き要素を一括で組み立てて画面をダイナミックに書き換えるWebプログラミングの本質的な仕組みを理解しました!
